# What is a Prediction Interval?

When a model predicts "45 cases next month," that single number hides something important: *how confident is the model in that prediction?*

A **prediction interval** answers that question. Instead of one number, the model gives you a range - like "between 30 and 70 cases." That range tells you how much uncertainty exists in the forecast.

## The weather forecast analogy

Think about weather forecasts. A forecaster could say:

- *"Tomorrow will be 20°C"*
- *"Tomorrow will be between 18°C and 22°C"*

The second version is more honest - and more useful. If you're planning an outdoor event, knowing the range helps you prepare for the best and worst cases.

Disease forecasting works the same way. A model that says "expect between 80 and 150 cases" is giving you actionable information: you can plan for the likely scenario (around the middle of the range) while also preparing for the upper end.

## How prediction intervals work in Chap

Chap displays two prediction intervals on every forecast chart. These ranges describe what the model believes is plausible, not a guarantee about what will happen:

- **50% interval** (inner band) - The model assigns about a 50% chance to the actual value falling within this narrower range. Think of this as the model's "likely zone."
- **80% interval** (outer band) - The model assigns about an 80% chance to the actual value falling within this wider range. Think of this as the model's "safe planning zone."

The **median** line running through the middle is the model's best single estimate.

At 90% or 95%, the band widens considerably because the model is including more of the outcomes it believes are possible. If a model is poorly calibrated, the real value may still fall outside these ranges more often than the percentage suggests.

## Reading the bands

When you see a prediction chart in Chap, here's how to read it:

1. **The median line** is the single best guess. If you had to pick one number, this is it.
2. **The inner band (50%)** shows the model's narrower likely range. If the model is well-calibrated, about half of comparable observations should land inside this band.
3. **The outer band (80%)** shows a wider model uncertainty range. If the model is well-calibrated, about four out of five comparable observations should land here.

If the actual observed value falls *outside* the outer band, that's noteworthy - it means something unusual happened that the model didn't expect.

## Wider isn't always worse

It's tempting to think narrow bands are always better, but that's not quite right.

A model with unrealistically narrow bands is **overconfident**. It's claiming more certainty than it actually has. When the real values fall outside those narrow bands too often, the model's uncertainty estimates aren't trustworthy.

Wide bands are the model being *honest* about what it doesn't know. This can happen when:

- The model has limited training data
- The disease pattern is genuinely unpredictable
- The forecast is far into the future (uncertainty grows with time)
- An unusual event is affecting the pattern

A well-calibrated model - one whose intervals are the right width - is more valuable than one that looks precise but is frequently wrong.
